# YDST Admin Dashboard

Admin dashboard prototype for YDST 2026. Sample data only (fictional learners).

- **Overview**: registration-to-enrolment funnel, best-score mix, score distribution, follow-up lists
- **Registration fees**: ₹100 one-time fee payments and every payment attempt
- **Test results**: one row per monthly attempt, scores out of 60, discount earned (31+ 15%, 41+ 30%, 51+ 50%), scholarship codes

Click any learner to open a profile with both their fee and their test history.

Live: https://abhinavthak.github.io/ydst-payments-dashboard/
